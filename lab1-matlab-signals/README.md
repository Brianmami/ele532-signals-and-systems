# ELE 532 Lab 1 – Working with MATLAB Functions and Signals

**Course:** ELE 532 – Signals and Systems I  
**Tools:** MATLAB

## Overview

- **A–B:** plotting continuous-time signals with anonymous functions, including unit steps and ramps
- **C:** time shifting, scaling and reflection of signals
- **D:** array indexing and vectorized operations on a data set, including thresholding a matrix and processing an audio signal (D1–D3)

## Build / run

Run each script in MATLAB.

## Notes

Part D loads `ELE532_Lab1_Data.mat`, the course-provided data file in this folder.
